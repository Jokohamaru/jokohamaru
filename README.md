### Các mảng kỹ thuật đang tập trung tìm hiểu & thực hành

- **Infrastructure as Code (IaC):** Quản lý hạ tầng dưới dạng mã nguồn với Terraform và Ansible — hướng tới tính nhất quán, dễ tái tạo môi trường và kiểm soát thay đổi rõ ràng qua Git.
- **CI/CD & GitOps:** Tự động hóa luồng build, kiểm thử và triển khai ứng dụng container bằng GitHub Actions, GitLab CI/CD, Jenkins và Argo CD trên Kubernetes.
- **Hạ tầng đám mây & Bảo mật (Cloud & Security):** Thiết kế mạng VPC phân lớp, làm quen với kiến trúc đa vùng khả dụng (Multi-AZ), cân bằng tải và tuân thủ nguyên tắc phân quyền tối thiểu (Least Privilege) trên AWS.
- **Giám sát hệ thống (Monitoring & Logging):** Thiết lập thu thập metrics, logs và cảnh báo cơ bản với Prometheus, Grafana và CloudWatch để theo dõi sức khỏe hệ thống và chi phí tài nguyên.
